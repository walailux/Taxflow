# ฟอนต์ไทยสำหรับสร้าง PDF/A-3

โฟลเดอร์นี้ต้องมีไฟล์ 2 ไฟล์ ซึ่ง **ไม่ได้มากับที่เก็บโค้ด** ต้องดาวน์โหลดเอง

```
Sarabun-Regular.ttf
Sarabun-Bold.ttf
```

## ทำไมต้องมี

PDF/A ห้ามใช้ฟอนต์ที่ไม่ฝังลงในไฟล์ เพราะไฟล์ต้องเปิดอ่านได้เหมือนเดิมในอีกสิบปีข้างหน้า
โดยไม่ต้องพึ่งฟอนต์ที่ติดตั้งอยู่ในเครื่องผู้อ่าน ระบบจึงต้องมีไฟล์ฟอนต์จริงมาฝัง

## ทำไมเลือก Sarabun

* มีตาราง OpenType ครบ สระและวรรณยุกต์ไทยจึงลอยถูกตำแหน่ง ซึ่งเป็นความเสี่ยงที่แผน ver18 ระบุไว้
* สัญญาอนุญาต SIL Open Font License 1.1 แจกจ่ายและฝังในไฟล์ PDF ได้โดยไม่เสียค่าใช้จ่าย
* เป็นฟอนต์ที่กรมส่งเสริมอุตสาหกรรมเผยแพร่ ใช้ในเอกสารราชการไทยทั่วไป

## วิธีดาวน์โหลด

1. เข้า <https://fonts.google.com/specimen/Sarabun>
2. กด Get font แล้ว Download all จะได้ไฟล์ zip
3. แตกไฟล์แล้วคัดลอก `Sarabun-Regular.ttf` กับ `Sarabun-Bold.ttf` มาไว้ในโฟลเดอร์นี้

ตรวจว่าวางถูกที่ด้วย `npm run pdf:sample` ถ้ายังไม่ครบจะบอกว่าขาดไฟล์ไหน

## ใช้ฟอนต์อื่นแทนได้ไหม

ได้ แต่ต้องตรวจสองอย่างก่อน คือสัญญาอนุญาตต้องอนุญาตให้ฝังในเอกสาร
และต้องทดสอบคำที่มีสระซ้อนกับวรรณยุกต์ เช่น "ผู้ซื้อ" "เกื้อกูล" "ที่อยู่"
ถ้าเปลี่ยนฟอนต์ ให้ตั้งชื่อไฟล์ให้ตรงกับที่ `lib/pdfbuild.js` มองหา
หรือตั้ง `TAXFLOW_FONT_DIR` ชี้ไปโฟลเดอร์อื่น
